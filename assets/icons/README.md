# İkon Dosyaları

Build için gerekli ikon dosyaları bu klasöre yerleştirilmeli:

| Dosya        | Boyut          | Platform              |
|-------------|----------------|-----------------------|
| icon.ico    | 256x256        | Windows               |
| icon.icns   | 1024x1024      | macOS                 |
| icon.png    | 512x512        | Linux / Electron      |
| icon-16.png | 16x16          | Windows taskbar       |
| icon-32.png | 32x32          | Windows               |

Araç önerisi: https://www.icoconverter.com  veya  `electron-icon-builder` paketi.
